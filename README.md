# AtomVision Student Project Website

A static website mockup for a student science project about the structure of the atom and India's three-stage nuclear programme proposed by Homi J. Bhabha.

## What to add next

1. Replace the gallery placeholders with photos and videos of the physical model.
2. Add downloadable research PDFs, presentation slides, diagrams, and source lists.
3. Record an explanation video covering the model, how it works, benefits, safety, and credits.
4. If building a multi-student platform, add student accounts, upload storage, moderation, search, project categories, and teacher approval.

## Running locally

Open `index.html` in a browser or serve the folder with any static file server.
